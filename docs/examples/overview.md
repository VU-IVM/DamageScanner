# Examples

This section contains interactive examples demonstrating how to use `DamageScanner` for different types of hazard and exposure data. These examples use real-world data from the Kampen case study.

## Interactive Notebooks

To see the tool in action with real-world data and visualizations, explore our interactive Jupyter Notebook examples:

- 📊 **[Vector-based assessment](vector-based.ipynb)** — Demonstrates how to use OpenStreetMap (OSM) polygons and points (e.g., land use, buildings) with raster hazard maps.
- 🗺️ **[Raster-based assessment](raster-based.ipynb)** — Shows how to perform rapid large-scale analysis using land-use rasters and gridded hazard data.
